# 外贸利润计算器 (Profit Calculator)

快速计算外贸订单成本与利润空间的在线工具。

## 技术栈

- **前端**: 原生 HTML/CSS/JS
- **部署**: Docker + Nginx
- **端口**: 7003

## 功能

- 💰 **多维度成本核算** — 采购成本、运费、关税、保险费等
- 📊 **利润分析** — 毛利率、净利润率、ROI 等关键指标
- 🔢 **实时计算** — 输入即计算，无需提交
- 🌍 **多币种支持** — 人民币/美元汇率换算
- 🎨 **绿色主题** — 深绿渐变金融风格

## 成本项

| 类别 | 计入项 |
|------|--------|
| 货物成本 | 采购单价、数量、包装费 |
| 运输费用 | 海运费、陆运费、快递费 |
| 关税税费 | 关税税率、增值税 |
| 其他费用 | 保险费、银行手续费、佣金 |

